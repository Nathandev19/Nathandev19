### Ce qui m'intéresse techniquement

Faire en sorte qu'un système à base de LLM soit **vérifiable**. Un modèle qui réécrit un CV ou qui chiffre une offre produit une sortie plausible : plausible n'est pas vrai. Le travail intéressant est de construire les instruments qui le prouvent — appariement à la source, fenêtres de comparaison indépendantes de la mise en page, fixtures d'appels rejouées pour tester à coût nul, mesures prises sur la page rendue plutôt que déduites du code.

Deux règles que j'applique, payées par des défauts réels :
un zéro n'est une preuve que si l'instrument a d'abord montré qu'il savait rendre non-zéro ;
une correction n'est close que mesurée là où l'utilisateur la voit.
